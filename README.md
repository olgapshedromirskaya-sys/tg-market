# Свой собственный маркетплейс Telegram Mini App

Готовый шаблон мини‑приложения интернет‑магазина/маркетплейса для Telegram:

- тёмно‑синяя витрина в стиле маркетплейсов (без копирования фирменных цветов);
- карточки товаров в 2 колонки (как в классическом каталоге);
- в карточке товара отображаются только: фото, цена, название, кнопка перехода;
- без рейтинга и без блока доставки;
- детальная страница товара: описание, краткие характеристики, внешняя ссылка на маркетплейс;
- кнопка «← Вернуться на главную» в верхней части экрана.

## 1) Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## 2) Подключение базы Supabase (опционально)

Если переменные окружения не заданы, будут показаны демо‑товары.

Создайте файл `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_ANON_KEY
```

Пример таблицы:

```sql
create table if not exists public.products (
  id uuid primary key default gen_random_uuid(),
  title text not null,
  description text not null,
  price numeric not null default 0,
  image text not null,
  short_specs jsonb,
  marketplace_url text,
  created_at timestamptz not null default now()
);
```

Пример поля `short_specs`:

```json
["Объём: 500 мл", "Тип: натуральный", "Срок годности: 12 мес"]
```

## 3) Как прикрепить готовое Mini App к Telegram‑боту (подробно)

### Шаг 1. Подготовьте production URL (HTTPS)

Telegram Mini App открывается только по HTTPS.

Если нужно, чтобы всё работало по **прежней ссылке**:

1. Деплойте в тот же проект (например, тот же проект на Vercel).
2. Не меняйте production domain.
3. После обновления кода у вас останется тот же URL, например:
   `https://your-mini-app-domain.com`

### Шаг 2. Создайте или выберите бота в BotFather

1. Откройте `@BotFather`.
2. Если бота ещё нет: команда `/newbot`.
3. Задайте имя и username бота.
4. Сохраните токен бота (`BOT_TOKEN`).

### Шаг 3. Назначьте кнопку меню (Menu Button) для запуска приложения

Вариант через команды BotFather:

1. `/setmenubutton`
2. Выберите нужного бота.
3. Укажите текст кнопки (например, `Открыть магазин`).
4. Укажите URL Mini App:
   `https://your-mini-app-domain.com`

После этого в чате с ботом появится постоянная кнопка запуска мини‑приложения.

### Шаг 4. Создайте публичную App-ссылку (рекомендуется)

1. В `@BotFather` выполните `/newapp`.
2. Выберите бота.
3. Заполните поля:
   - название приложения;
   - short name (короткое имя);
   - описание;
   - URL приложения (тот же HTTPS адрес);
   - иконку/изображение (если запрашивается).
4. Получите ссылку вида:
   `https://t.me/<bot_username>/<app_short_name>`

Эту ссылку можно размещать в канале, описании профиля и рекламе.

### Шаг 5. Прикрепите Mini App к Telegram‑каналу

1. Добавьте бота в администраторы канала.
2. Дайте право публиковать сообщения.
3. Опубликуйте:
   - либо прямую app-ссылку `https://t.me/<bot_username>/<app_short_name>`;
   - либо пост с inline-кнопкой `web_app`.

Пример отправки поста через Bot API:

```bash
curl -X POST "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/sendMessage" \
  -H "Content-Type: application/json" \
  -d '{
    "chat_id":"@your_channel_username",
    "text":"Открыть магазин",
    "reply_markup":{
      "inline_keyboard":[
        [{"text":"Перейти в Mini App","web_app":{"url":"https://your-mini-app-domain.com"}}]
      ]
    }
  }'
```

### Шаг 6. Проверка после привязки

Проверьте запуск в 3 сценариях:

1. Из меню кнопки бота.
2. По app-ссылке `https://t.me/<bot_username>/<app_short_name>`.
3. Из поста канала с inline-кнопкой.

Чек‑лист:

- открывается главная страница с каталогом;
- карточки в 2 колонки;
- в карточках нет рейтинга и доставки;
- переход в детальную карточку работает;
- кнопка «← Вернуться на главную» работает;
- ссылка маркетплейса в описании товара открывается корректно.

## 4) Где редактировать товары

Товары читаются из таблицы `products`:

- `title` — название;
- `price` — цена;
- `image` — ссылка на фото;
- `description` — описание;
- `short_specs` — краткие характеристики;
- `marketplace_url` — внешняя ссылка на товар (WB/Ozon/ЯМ и т.д.).

Если `marketplace_url` пустой, на странице товара показывается подсказка, что ссылку можно добавить.
